# Python Project

A simple Python project containing programs for basic operations and displaying a name.

## Files

* `square.py` — Calculates the square of a number.
* `addition.py` — Adds two numbers.
* `name.py` — Prints a name.

## Usage

Run any Python file using:

```bash
python filename.py
```

For example:

```bash
python square.py
python addition.py
python name.py
```
